LES MERS DE L'ASCENSION — application mobile (cartes v25)
==========================================================

Ce dossier contient l'application complète :
  index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png
Envoyez les 5 fichiers ensemble ; ce guide (LISEZ-MOI.txt) n'est pas nécessaire en ligne.


1. LA METTRE EN LIGNE (une seule fois, gratuit)
-----------------------------------------------
Le plus simple : GitHub Pages.
  a. Sur la page de votre dépôt GitHub, cliquez « uploading an existing file » (ou « Add file » > « Upload files »).
  b. Glissez les 5 fichiers, puis « Commit changes ».
  c. Onglet « Settings » > « Pages » > Source : « Deploy from a branch »,
     Branch : « main » et « / (root) » > « Save ».
  d. Attendez 1 à 2 minutes. Pour le dépôt William-tech/Mers, l'adresse sera :
     https://william-tech.github.io/Mers/


2. L'INSTALLER SUR CHAQUE TÉLÉPHONE
-----------------------------------
Ouvrez l'adresse, puis :
  - Android (Chrome) : menu ⋮ > « Installer l'application » ou « Ajouter à l'écran d'accueil ».
  - iPhone (Safari) : bouton Partager > « Sur l'écran d'accueil ».


3. JOUER ENSEMBLE
-----------------
  - Un joueur touche « Créer une partie » : son téléphone affiche un code de 4 lettres
    (par exemple BWAN). C'est lui qui fait jouer les bots ; il garde l'application ouverte.
  - Les autres touchent « Rejoindre une partie » et tapent ce code.
  - Ajoutez des bots si vous voulez (2 à 5 joueurs au total), puis « Lancer la partie ».
  - Pour jouer seul : « Jouer seul contre des bots » (fonctionne sans internet).

Internet (Wi-Fi ou données) est nécessaire au moment de créer le code et de rejoindre :
un service gratuit (PeerJS) sert à mettre les téléphones en relation. Ensuite, les
téléphones jouent en direct entre eux. En général, il n'est même pas obligatoire
d'être sur le même Wi-Fi.

Pendant la partie, chaque téléphone a 4 onglets :
  Navire (vos cartes et vos valeurs de dé), Marché, Équipage (les autres joueurs), Journal.
Le panneau du bas montre les dés et ce que vous devez décider.


4. SI ÇA NE SE CONNECTE PAS
---------------------------
  - « Aucune partie ouverte avec ce code » : vérifiez les lettres (il n'y a jamais de I ni de O),
    et que l'hôte est toujours sur l'écran de la partie.
  - « Impossible de joindre le service de mise en relation » : il manque internet,
    ou le service gratuit est momentanément indisponible ; réessayez un peu plus tard.
  - Tous les téléphones doivent avoir la même version : en cas de message
    « Version différente », rechargez l'application sur chacun.
  - Un téléphone qui ne donne plus de nouvelles pendant 1 minute est remplacé par
    un bot. Il ne peut pas revenir dans cette partie, mais l'hôte peut relancer
    une partie avec le même équipage.
